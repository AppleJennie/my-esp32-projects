# my-esp32-projects

我的 ESP32 项目合集仓库，包含四个子项目：

- **OV-Watch/** — OV-Watch 开源智能手表项目存档（硬件、固件、上位机软件，保留原作者 LICENSE）
- **xiaozhi-sleep-monitor/** — 基于小智 ESP32 二次开发的睡眠健康监测系统（鼾声分析、呼吸事件监测）
- **moji2-firmware/** — Moji 2.0 桌面机器人自研固件（ESP32-C5，1.5 寸圆屏 + 音频 + WiFi）
- **xiaozhi-sxh-assistant/** — 小智云端部署 + 《恋与深空》沈星回角色化（腾讯云服务端、人设 prompt、音色克隆文档，moji 复刻分析）
