# AI 睡眠床头监护仪 — 技术路线报告

## 一、项目概述

本项目研制一款基于 **ESP32-S3** 的 AI 睡眠床头监护仪，通过非接触式音频传感器（INMP441 MEMS 麦克风）采集夜间鼾声信号，结合 **TensorFlow Lite Micro** 端侧 AI 推理引擎和声学频谱分析，实现鼾声自动检测、分型分类与睡眠呼吸事件筛查。设备以 4.3 英寸 RGB LCD 呈现深色主题仪表盘，支持独立工作或通过 UART 协议与毫米波雷达主板协同融合。

## 三、核心技术路线

### 3.1 音频采集与预处理

**技术方案**：INMP441 MEMS 麦克风 → I2S1 接口 → 环形缓冲区 → 窗口选择

| 参数 | 规格 |
|------|------|
| 采样率 | 16 kHz |
| 量化 | 24-bit → 16-bit (右移14位) |
| 环形缓冲 | 4 秒 (64000 samples) |
| 分析窗口 | 1 秒 (16000 samples) |
| 帧长 | 32ms / 帧步 16ms |

**关键技术点**：
- 软件 DC 阻断滤波器 (α=0.995)，消除 MEMS 直流偏移
- 基于 RMS + Peak + ZCR + Clipping 的 4 维度窗口评分算法，从 4 秒缓冲区中自动选择最优 1 秒分析窗口
- 麦克风有效性自检 (峰值 > 20、信号变化 > 1000)

### 3.2 AI 推理引擎

#### 3.2.1 Micro Frontend 音频特征提取

移植自 TensorFlow Lite Micro 官方 `micro_speech` 示例的完整前端处理链路：

```
PCM (16kHz) → Hamming Window → FFT (256pt) → Mel Filterbank (30ch)
    → PCAN Gain Control → Log Scale → 量化 uint8 → 1830维特征向量
```

| 组件 | 参数 |
|------|------|
| FFT | 256 点, Kiss FFT int16 实现 |
| Mel 滤波器组 | 30 通道, 40Hz–6kHz |
| PCAN 增益控制 | strength=0.95, offset=80 |
| Log Scale | shift=6 |
| 量化 | value × 128 / 335, 截断至 [0, 255] |
| 输出维度 | 30 (频率) × 61 (时间) = 1830 |

#### 3.2.2 TFLite Micro 推理

```
输入: 1830 × uint8
模型: snore_detection.tflite (量化 int8)
输出: snore_score (0–255), 数值越高表示鼾声特征越明显
推理帧率: 约每 480ms 一次 (7680 新样本到达时触发)
```

### 3.3 混合决策引擎 (AI + 规则)

本系统采用 **"AI 感知 + 规则决策"** 的双层架构，兼顾模型泛化能力和工程可控性。

#### 3.3.1 P1/P2 稳定性状态机

```
                        ┌─────────────┐
          score≥140     │             │   score<50×2帧
          ZCR<0.25      ▼   SNORE     │   强退
        ┌───────────→  ACTIVE  ────────────┐
        │              │             │      │
    ┌───┴───┐          │  保持10秒   │      ▼
    │ IDLE  │          └────┬────────┘  ┌──────┐
    │       │◄──────────────┘           │ IDLE │
    └───────┘   off计数≥2              └──────┘
```

| 状态机参数 | 值 | 作用 |
|-----------|-----|------|
| 强命中阈值 | score ≥ 140 | 确认鼾声信号 |
| 弱命中阈值 | score ≥ 80 | 维持活跃状态 |
| 零交叉率门控 | ZCR < 0.25 | 排除高频噪声 |
| 进入条件 | 3帧中≥1帧命中 | 快速响应鼾声开始 |
| 保持时间 | 10 秒 | 短暂停顿不退出 |
| 强退阈值 | score < 50 | 连续 2 帧才强制退出 |

#### 3.3.2 规则型鼾声四分类器 (snore_classifier)

基于声学频谱特征的多维度评分分类：

| 类型 | 频谱质心 (Hz) | 关键特征 | 权重 |
|------|-------------|----------|------|
| 鼻型 (Nasal) | 600–1500 | harmonic ≥ 0.35 | centroid×0.5 + harmonic×0.5 |
| 喉型 (Throat) | 150–600 | low_freq > 0.55 | centroid×0.5 + low_freq×0.5 |
| 口型 (Mouth) | >1500 | harmonic < 0.20 | centroid×0.5 + harmonic×0.5 |
| 混型 (Mixed) | 三者分数均 < 0.3 时判定 | — |

### 3.4 声学频谱并行分析 (snore_audio_analyzer)

独立于 AI 模型运行的第二分析通道，提供互补的声学特征：

- **频谱质心** (80–3000 Hz 范围)
- **低频能量占比** (150–600 Hz 频带)
- **谐波比** (基频 80–300 Hz, 检测至第 4 次谐波, 30Hz 搜索窗)
- **气流声检测** (centroid > 800Hz + 低谐波 + 高 ZCR)
- **恢复呼吸检测** (6 秒静默后 RMS 突增, 保持 1.5 秒)
- **鼾声分型置信度**: 综合模型分数 + RMS 能量 + 信号质量

### 3.5 事件检测与统计 (snore_event_detector)

- **120 帧滑动历史** (约 8 分钟, 每帧 4 秒)
- **鼾声片段合并**: 连续 `is_snoring=true` 帧合并为一次鼾声事件
- **统计窗口**: 1 分钟 / 10 分钟
- **输出**: 各类型鼾声次数、累计时长、最长单次、AHI 估算

### 3.6 双板协同通信协议

```
  NODE 板 (本项目)              MAIN 板 (对端)
  ┌─────────────┐    UART2     ┌─────────────┐
  │ 音频采集     │────snore────→│ 雷达感知     │
  │ AI鼾声检测   │   report    │ 融合决策     │
  │ 声学分型     │←──main─────│ 健康评估     │
  │ UI 显示      │   report    │             │
  └─────────────┘             └─────────────┘
```

本板负责音频域的鼾声检测与分型，通过 UART2 (115200bps) 发送 `snore_report` 帧给对端主板；对端主板回传 `main_report` 帧，包含融合后的 AHI、血氧、体态、事件置信度等综合指标。

### 3.7 LVGL 人机交互界面

- **框架**: LVGL v8.4.0, 800×480 横屏, RGB565 色彩
- **缓冲**: 双缓冲 (800×40×2 = 64KB × 2, PSRAM)
- **设计风格**: 深色主题 (#0D1117 背景), GitHub-dark 配色体系
- **字体**: 自定义 16px 中文位图字体 (Noto Sans SC 提取, 4bpp 抗锯齿)

## 四、技术创新点

### 创新点 1：端侧 AI + 声学规则 混合决策架构
**问题**：纯 AI 模型在嵌入式端受限于模型容量和训练数据覆盖，泛化边界不确定；纯规则方法难以适应复杂声学环境。

**方案**：TFLite Micro 模型输出"鼾声相似度"分数 (0–255) → P1/P2 状态机做时间维度稳定化 → 规则型分类器 + 频谱分析器做细粒度分型。三层叠加，AI 负责泛化感知，规则负责可控决策。

**优势**：
- 模型无需完美，分数 140 即可触发（传统方案要求概率 > 0.9）
- 阈值可在线调整，无需重新训练模型
- 频谱分类器提供可解释的声学依据

### 创新点 2：完整 Micro Frontend 前端的嵌入式移植
将 TFLite Micro 官方的 `micro_speech` 前端链路 (Hamming窗→FFT→Mel滤波器组→PCAN增益控制→Log Scale→量化) 完整移植至 ESP32-S3，适配 16kHz 单声道鼾声检测场景，38 个独立 C/C++ 模块协同工作。

### 创新点 3：双维度并行声学分析
AI 模型 (时频特征 + 神经网络) 与频谱分析器 (质心/谐波/低频比) 双通道并行运行，互为补充。AI 通道捕获深度特征，频谱通道提供可解释的声学参数和分型依据，两者融合提高整体检测鲁棒性。

### 创新点 4：自适应窗口选择算法
4 秒环形缓冲区中，基于 RMS能量 + Peak峰值 + ZCR过零率 + Clipping削波 的四维评分函数，自动选择分析质量最高的 1 秒窗口，避免环境瞬态噪声干扰。

### 创新点 5：自定义深色主题仪表盘
脱离 SquareLine Studio 图形化工具，纯代码构建 800×480 深色主题仪表盘，采用 GitHub-dark 配色体系，支持圆环进度、实时波形、半透明浮层等高级 UI 组件，全部中文字体按需提取（4bpp 抗锯齿），内存占用极低。
